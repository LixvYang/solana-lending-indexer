# 分镜

给作者拍摄用,与读者文档 `docs/chapters/` 分开。写作顺序是**先写文档,再从文档提炼分镜**:文档要求准确,分镜要求节奏。

## 拍摄顺序(与发布顺序不同)

先拍 EP2 → EP7,**最后拍 EP1**。成品和细节定型之后,开场演示才不会和后面几集矛盾。

## 每集开拍前

```bash
git checkout epN-end          # 回到这一集的代码检查点(tag),见仓库根 README
docker compose up -d
pnpm exec tsx scripts/reindex.ts   # 需要干净数据时:清库后 ingest --backfill
```

## 每集都要说的一句话(诚实声明)

> 价格是"布局一致的 mock":devnet 上 Switchboard 的 oracle 目前整体离线,所以价格由我们自己写入一个与真实账户字节布局完全一致的账户。除此之外,程序、交易、清算都是真实的。
