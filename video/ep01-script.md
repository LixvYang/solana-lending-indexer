# EP1 成品演示(目标 6–8 分钟)

**一句话结论**:一笔链上借款,怎么变成数据库里的一行、网页上的一个数字。**最后拍。**

| 时间 | 画面 | 旁白要点 | 操作 |
|---|---|---|---|
| 0:00 | 页面全景 | 这是一个真实部署在 devnet 上的借贷池;后面六集我们把它从下往上拆开 | 打开 `http://localhost:5173` |
| 0:30 | 总览 + 池子表 | 存款、借款、利用率、利率,每个数字都能追溯到链上的某几个字节 | 指着总存款 |
| 1:30 | 利率曲线 | 当前利用率落在曲线哪里;借款利率比存款利率高,差额是协议费 | 鼠标在曲线上移动 |
| 2:30 | 账户表 | 健康度小于 0 就可以被清算;**这个数和程序自己算的对得上到小数点后六位**(EP7 证明) | 指着状态标签 |
| 3:30 | **X 光** | 点一笔借款:左边原始字节,中间解码,右边数据库行——三种样子,同一件事 | 点 `lending_account_borrow`,鼠标移到字节段,中栏同步高亮 |
| 5:00 | 架构图(`ep01-demo.md`) | 先存原始、再解码、幂等、状态优先于事件——三条原则贯穿全程 | 切到架构图 |
| 6:00 | 路线表 | 七集的路线;只想了解皮毛看 EP1、EP2 | |
| 6:30 | **诚实声明** | 价格是布局一致的 mock(见 README 的声明) | 切到 `docs/chapters/ep03` 的价格一节 |
| 7:00 | 片尾 | 下一集:先把 Solana 的数据地图画清楚 | |

**置顶评论**:`docs/cheatsheet.md` 的速查图。
