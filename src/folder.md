# src

最终代码按模块组织，不按章节复制；raw_tx 是交易事实来源。

| 目录 | 角色 | 功能 |
|---|---|---|
| core/ | 字节与计算 | base58、小端读取、精确金额/分数 |
| decoder/ | 纯解码 | 指令/事件/账户布局、对账与重放版本 |
| store/ | 存储 | SQL 迁移、原始事实、解码重放、账户快照 |
| ingest/ | 采集 | finalized RPC、取块、签名回填和事务游标 |
| api/ | 视图与钱包 API | M5a 只读视图；M7a 注入 RPC 构建/转发/钱包信息 |

| faucet/ | 独立水龙头 | 专用钱包转账、限流与管理员 setup 指令 |
| keeper/ | 独立价格维护 | 保持精确链上 mock 价格、时间戳刷新与容错调度 |

SYNC: 模块增删或职责变化时同步本表和 README。
